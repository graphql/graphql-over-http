# GraphQL-over-HTTP Specification Contribution Guide

GraphQL-over-HTTP is still an evolving protocol. This repository contains the
specification text as well as Pull Requests with suggested improvements and
contributions.

This repository follows the same contribution process as the GraphQL
Specification; please see
[graphql-spec/CONTRIBUTING.md](https://github.com/graphql/graphql-spec/blob/main/CONTRIBUTING.md)
for details.
